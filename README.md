

PROJECT OVERVIEW:
This project demonstrates practical skills in comparing AI-generated responses, evaluating response quality, and selecting the stronger answer using structured criteria.

OBJECTIVES:
Compare two AI-generated responses to the same question.
Assess accuracy, relevance, completeness, clarity, and safety.
Identify unsupported claims and missing information.
Rank responses and justify preferences with clear reasoning.
Apply consistent evaluation criteria.

EVALUATION CRETERIA:
Criterion
What I Assess

Accuracy
Whether claims are correct and supported
Relevance
Whether the response answers the question
Completeness
Whether important information is included
Clarity
Whether the response is understandable
Safety
Whether the response avoids harmful or misleading advice
 
SKILLS DEMONSTRATED:
Critical thinking
Comparative analysis
Evidence-based reasoning
Quality assessment
Written justification
Attention to detail

 PROJECT SCOPE:
This is an educational portfolio project designed to practise general AI response evaluation. The examples are practice exercises and do not represent paid professional experience or formal certification.
